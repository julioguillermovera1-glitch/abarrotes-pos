CÓMO INSTALAR ABARROTES POS EN UN LOCAL NUEVO
================================================

FORMA FÁCIL (recomendada) — un solo archivo
--------------------------------------------
1. Copia el archivo "Instalar.bat" al computador del local nuevo
   (por USB, WhatsApp, correo, como sea — es un archivo chico).
   No hace falta copiar nada más, este archivo descarga todo el resto solo.

2. Haz doble clic en "Instalar.bat".

3. Windows va a pedir confirmación para correr como Administrador —
   acepta (es necesario para instalar el programa y la base de datos).

4. El computador necesita internet en este paso: descarga el programa
   desde GitHub, y si faltan, instala Node.js y MariaDB. Puede tardar
   varios minutos la primera vez.

5. Al final se abre el programa solo, en su propia ventana (sin barra de
   direcciones ni pestañas, no se ve como una página de Chrome), en la
   pantalla de inicio de sesión.
   Usuario: admin
   Contraseña: admin123

6. IMPORTANTE: cambia esa contraseña apenas entres, en el menú
   "Usuarios" → botón "Restablecer contraseña".

7. El programa no es solo para almacenes de abarrotes: en el menú
   "Configuración" puedes poner el nombre real de tu local y subir tu
   propio logo — aparecen en el login, el menú y el ticket de venta.

FORMA ALTERNATIVA — sin depender de GitHub en el momento
----------------------------------------------------------
Si prefieres copiar el programa completo por USB (por ejemplo, sin
buena conexión a internet en ese momento):
1. Copia toda la carpeta "AbarrotesPOS" al computador nuevo.
2. Haz doble clic en "Instalar.bat" que está DENTRO de esa carpeta
   — al estar ya la carpeta ahí, no descarga el programa de nuevo,
   sigue directo con la instalación de Node.js/MariaDB y el resto.
   (Node.js y MariaDB sí se siguen descargando por internet en este paso.)

Después de instalado:
- El programa se abre solo cada vez que se prende el computador.
- Todas las noches a las 23:30, y también cada vez que se prenda el
  computador, se hace un respaldo automático de la base de datos (queda
  guardado en la carpeta "backups" dentro de la carpeta AbarrotesPOS,
  se conservan los últimos 30 días).
- Si el programa se cae solo (se cierra o deja de responder), se revisa
  cada 5 minutos y se reinicia automáticamente, sin que nadie tenga que
  hacer nada. Si es el servicio de MariaDB el que se cae, Windows lo
  reinicia solo también.
- Queda un acceso directo en el escritorio para abrir el programa cuando
  quieras, en su propia ventana (no en una pestaña del navegador).

SI ALGO SE ROMPE DE VERDAD
----------------------------
- "Reparar.bat" (en la carpeta AbarrotesPOS): vuelve a dejar todo en
  orden — Node.js, MariaDB, dependencias, estructura de la base de
  datos — SIN borrar tus datos (ventas, inventario, clientes, usuarios
  y contraseñas quedan igual). Úsalo si el programa dejó de abrir o algo
  se ve raro.
- Si además necesitas volver la base de datos a un punto anterior (por
  ejemplo, si se corrompió de verdad y "Reparar.bat" no alcanza), abre
  PowerShell como Administrador dentro de la carpeta AbarrotesPOS y
  ejecuta:
    powershell -ExecutionPolicy Bypass -File .\scripts\restaurar-respaldo.ps1
  Te muestra la lista de respaldos guardados y pide confirmación antes
  de reemplazar los datos actuales — no se hace nunca de forma
  automática, porque restaurar un respaldo viejo borra las ventas
  hechas después de esa fecha, y eso lo debe decidir una persona, no el
  programa solo.

Si quieres conectar este local al panel central (para que el dueño vea
las ventas de todas las tiendas), entra al programa y ve a
"🔗 Panel central" en el menú, con el código que te dé el dueño desde
su panel.

CONECTAR VARIOS PUESTOS/CAJAS AL MISMO COMPUTADOR
--------------------------------------------------
Solo UN computador (el "servidor") necesita tener AbarrotesPOS instalado.
Los demás puestos NO necesitan instalar nada — solo un navegador.

1. Al terminar la instalación, el instalador muestra una dirección como
   http://192.168.1.XX:4001 — anótala. Si la olvidas, en el computador
   servidor abre una ventana de "Símbolo del sistema" y escribe
   "ipconfig", busca la línea "Dirección IPv4".
2. En cada puesto adicional, conecta el computador a la misma red
   (WiFi o cable) que el servidor, abre un navegador, y entra a esa
   misma dirección.
3. Crea un usuario distinto para cada vendedora en el menú "Usuarios",
   así cada venta queda asociada a quien la hizo.

Notas:
- El computador servidor debe estar prendido y con el programa abierto
  para que los demás puestos puedan usarlo.
- Si el router asigna una IP nueva cada cierto tiempo, los otros puestos
  van a dejar de conectarse — pídele a quien instaló el router que le
  fije ("reserve") una IP fija a este computador.
